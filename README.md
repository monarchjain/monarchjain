## 🌟 Featured Projects

### 🧠 Multimodal Toxic Speech Detection

**Python · PyTorch · Hugging Face · Whisper · OpenCV · Librosa**

An AI/ML research project focused on detecting toxic and abusive speech in Hindi-English code-mixed videos by combining text, audio, and visual information.

- Combines text, speech, and visual features using a late-fusion approach.
- Uses IndicBERT, Wav2Vec 2.0, VGG16, Whisper, OpenCV, and Librosa.
- Evaluates performance using Accuracy, Precision, Recall, and F1-score.

🔗 **[View Project Repository](https://github.com/monarchjain/Multi-Toxicity-Detection-Code)**

### 📸 Employee Attendance Management System

**Python · Flask · MongoDB · OpenCV · Face Recognition · Firebase FCM**

An attendance solution using face recognition to support employee check-in and check-out workflows.

- Developed backend APIs for registration, recognition, and attendance.
- Implemented check-in order validation and shift status tracking.
- Added duplicate-face handling and push alerts for unknown faces.
- Built camera-side image capture and upload handling.

### ✈️ AeroBasket — Flight Booking App

**Flutter · Dart · Node.js · Express · MongoDB · JWT**

A full-stack flight-booking application with a Flutter client and a Node.js/Express REST API.

- Built flight search, cart, booking, and profile photo upload workflows.
- Implemented registration, login, OTP verification, and password reset.
- Designed MongoDB schemas and indexes.
- Integrated API responses and authentication into the mobile app.
